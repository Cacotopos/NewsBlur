Check: `git grep -n "FORK:" -- clients/ios ':!clients/ios/Fork'` must list exactly the source hooks below. The project-file hook can't hold a comment, because Xcode rewrites the file, so check it with `git grep -n "F04C0000000000000000F001" -- clients/ios/NewsBlur.xcodeproj/project.pbxproj`. That should give 4 lines: the group, the main-group child, and one per app target.

Fork-only code lives in `clients/ios/Fork/` and never conflicts on merge.

No-hook overrides: `ForkUI.install` swaps upstream's `SplitViewController` instance to `ForkSplitViewController` (`object_setClass`), which keeps `preferredDisplayMode` at `.secondaryOnly` and ignores `show(.primary/.supplementary)` while the fork owns the layout (every iPad window size since M7). If upstream ever adds stored properties or subclasses the split, revisit this.

The feed column opens a story by setting upstream's `pendingNotificationStory` (readonly in `NewsBlurAppDelegate.h`, set via KVC) before `loadFeed:withStory:`. That makes upstream look the story up by hash, the way it does for push notifications, instead of paging its hidden story list (which stalls after page 1 and gives up after 15 s). If upstream renames that property, story taps in the fork will log a KVC exception: check `ForkFeedColumnViewController.open(_:)` first.
